# Leaf-Downloader

A native Linux download manager inspired by IDM, powered by yt-dlp, written in Python with GTK4 and Libadwaita.

## Requirements

- Python 3.10+
- PyGObject
- Libadwaita
- yt-dlp

## Running

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python main.py
   ```
